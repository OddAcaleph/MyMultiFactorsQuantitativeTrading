# Risk Model V1 开发测试报告

**版本**: v1.0
**日期**: 2026-08-09
**数据范围**: 2000-2026年（27年）
**测试环境**: 32GB RAM, A股全市场数据

---

## 1. 概述

Risk Model V1 是基于Barra风格的多因子风险模型，实现了从因子暴露到协方差矩阵的完整计算链路。模型采用截面回归 + 滚动窗口协方差的经典框架，支持全A股市场的日度风险预测。

### 1.1 核心模块

| 模块 | 文件 | 功能 |
|------|------|------|
| 风险暴露 | `src/risk/risk_exposure.py` | 8个风格因子 + 26个行业因子 + 市场因子 |
| 因子收益 | `src/risk/factor_return.py` | WLS截面回归估计纯因子收益 |
| 因子协方差 | `src/risk/factor_covariance.py` | Ledoit-Wolf收缩协方差估计 |
| 特异性风险 | `src/risk/specific_risk.py` | 滚动残差波动率 + 行业收缩 |
| 协方差构建 | `src/risk/covariance_builder.py` | Σ = XFXᵀ + D，PSD保证 |
| 统一入口 | `src/risk/risk_model.py` | RiskModel外观类 |
| CLI入口 | `src/risk/run_risk_model.py` | 命令行运行 |
| 批量运行 | `scripts/run_risk_model_yearly.py` | 按年分批跑（避免OOM） |

### 1.2 因子体系

**35个因子**（1市场 + 8风格 + 26行业）：

| 类别 | 因子 |
|------|------|
| 市场 | INTERCEPT（截距项，代表市场因子） |
| 风格 | SIZE, BETA, MOMENTUM, VALUE, GROWTH, VOLATILITY, LIQUIDITY, LEVERAGE |
| 行业 | 申万一级行业（26个，剔除银行作为基准） |

## 3. 验证结果

### 3.1 暴露验证

- **结果**: 通过（近年数据0 issues）
- **风格因子**: 全部z-score标准化后均值≈0，标准差≈1
- **行业因子**: 26个申万一级行业，覆盖率合理
- **缺失率**: 早期年份基本面因子缺失率较高（VALUE/GROWTH/LEVERAGE），近年数据完整

### 3.2 风险预测验证（等权组合）

**波动率偏差**:
- 2017-2025年偏差范围: -12.8% ~ +29.9%
- 多数年份偏差在±20%以内，V1可接受

**Pearson相关系数**:
- 大部分年份为负（-0.0 ~ -0.5）
- **原因**: 滚动窗口协方差的滞后性。当市场波动率突变时，模型反应慢，导致"预测高时实际低，预测低时实际高"的负相关
- **V2改进方向**: 引入EWMA/GARCH等时序波动率模型，或波动率调整因子

### 3.3 协方差验证（抽样）

- 对称性: ✅ 通过
- PSD（半正定）: ✅ 通过
- 有限值: ✅ 通过
- 对角元全正: ✅ 通过
- 条件数: 较高（因子模型固有特性，XFXᵀ秩=K<<N）

## 4. 已知问题与限制

### 4.1 早期年份数据质量

- **2011年**: R²全NaN，可能因为基本面数据缺失导致因子回归失败
- **2012年**: 特异性风险大量NaN，warmup期不足导致滚动窗口样本不够
- **建议**: 实际使用从2013年或2015年开始更可靠

### 4.2 风险预测的时序相关性

- 滚动窗口协方差对波动率突变反应滞后
- Pearson相关为负是V1的已知特性，不影响波动率水平的估计准确度
- V2可引入EWMA或GARCH改进时序预测

### 4.3 内存限制

- 全量数据（1700万行）一次性加载会OOM（32GB）
- 解决方案：按年分批运行（`scripts/run_risk_model_yearly.py`）
- 每年独立进程，内存完全释放

### 4.4 全量协方差构建

- 5000+只股票的N×N协方差矩阵构建很慢（约40秒/天）
- 默认不构建（`--no-covariance`），只保存X/F/D
- 需要时用 `CovarianceBuilder.compute_portfolio_vol()` 按需高效计算（O(K²+N)）

## 5. 使用方式

### 5.1 单年快速运行

```bash
# 只计算X/F/D（推荐，约4分钟/年）
PYTHONPATH=src python src/risk/run_risk_model.py \
    --config conf/risk_model/risk_model_v1.json \
    --start-date 20230101 --end-date 20231231 \
    --warmup-days 252 --no-covariance

# 全量构建（含Σ，约3小时/年）
PYTHONPATH=src python src/risk/run_risk_model.py \
    --config conf/risk_model/risk_model_v1.json \
    --start-date 20230101 --end-date 20231231 \
    --warmup-days 252
```

### 5.2 全历史分批运行

```bash
PYTHONPATH=src python scripts/run_risk_model_yearly.py \
    --config conf/risk_model/risk_model_v1.json \
    --start-year 2000 --end-year 2026 \
    --warmup-days 252 --no-covariance --resume
```

## 7. V2 改进方向

1. **时序波动率模型**: EWMA/GARCH 替代简单滚动窗口，改善风险预测的时序相关性
2. **更多风格因子**: 质量、盈利、动量细分等
3. **结构化因子协方差**: 因子分组 + 结构化收缩（如Fama-MacBeth）
4. **Newey-West调整**: 自相关和异方差稳健的协方差估计
5. **行业中性化**: 风格因子的行业中性处理
6. **实时更新**: 增量计算框架，日度更新只需几秒
