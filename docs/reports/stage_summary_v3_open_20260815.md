## 一、数据处理流水线

### 1.1 流水线总览

```
raw_data (5.3GB) → cleaned_data (2.3GB) → processd_data (5.2GB)
     → features_data (12GB) → cross_sectional_processd_data (27GB) → generated_label (2.0GB)
```

数据来源：Tushare，覆盖 A 股全市场，时间跨度约 2000–2025 年。

### 1.2 各阶段说明

| 阶段 | 输入 | 输出 | 核心操作 |
|------|------|------|----------|
| **数据获取** | Tushare API | `raw_data/` | 日线行情、基本面、行业分类、ST/停牌等 |
| **数据清洗** | raw_data | `cleaned_data/` (2.3GB) | 去重、OHLC 校验、复权因子对齐 |
| **数据加工** | cleaned_data | `processd_data/` (5.2GB) | 宽表拼接（ST、停牌、复权、基本面、行业） |
| **特征计算** | processd_data | `features_data/` (12GB) | 66 个因子（价量、基本面、资金流、行业、增强 alpha） |
| **截面处理** | features_data | `cross_sectional_processd_data/` (27GB) | 每日 winsorize (1%) + Z-score 标准化 |
| **标签计算** | cross_sectional... | `generated_label/` (2.0GB) | 远期收益与排名标签（1d–20d 周期） |

### 1.3 特征体系（66 个因子）

- **价量类**：动量、波动率、换手率、成交量相关等
- **基本面类**：PE、PB、ROE、营收增速、毛利率等
- **资金流类**：主力资金、北向资金相关
- **行业类**：行业相对强弱
- **增强 alpha 因子**（~20 个）：MACD、RSI、52 周新高距离、OBV、营收加速度、毛利率变化等

## 三、Risk Model（风险模型）v1

### 3.1 模型架构

采用 Barra 风格的多因子风险模型，配置文件：`conf/risk_model/risk_model_v1.json`

| 组件 | 说明 |
|------|------|
| **风格因子** | 8 个：size, beta, momentum, value, growth, volatility, liquidity, leverage |
| **行业因子** | 申万一级行业（L1），26 个行业哑变量（剔除银行作为基准） |
| **总因子数** | 8 风格 + 26 行业 = **34 个因子** |
| **因子收益估计** | WLS（加权最小二乘），权重 = sqrt(20日成交额) |
| **因子协方差** | Ledoit-Wolf 收缩估计，回看 252 日，最少 60 日 |
| **特质风险** | 滚动标准差，回看 252 日，向行业-规模中位数收缩 |
| **Beta 估计** | 等权市场基准，回看 252 日 |
| **Size 因子** | 20日成交额中位数，对数变换 |
| **截面处理** | 1% winsorize + Z-score |

### 3.2 模型验证结果（以 2013 年为例）

| 指标 | 值 |
|------|-----|
| 截面 Pearson 相关（预测 vs 实现波动率） | **0.407** |
| 截面 Spearman 相关 | **0.450** |
| 正相关比例 | 100% |
| 五分位单调性 | ✅ 单调（Q1 1.44% → Q5 2.43% 日波动率） |
| Q5/Q1 波动率比 | 1.70x |

等权组合方差分解（2013 年中）：
- 市场因子（截距）：~99%
- 行业因子：~0.88%
- 特质风险：~0.05%
- 风格因子：≈ 0（等权组合风格中性）

> 风险模型的排序能力中等偏上（IC ~0.4），在组合优化中作为风险约束项使用。

### 4.2 优化问题形式

```
max_w    αᵀw - λ · wᵀΣw - TP · |w - w₀|
s.t.     Σwᵢ = 1                          (满仓约束)
         0 ≤ wᵢ ≤ max_weight              (个股权重上限)
         Σ|wᵢ - w₀ᵢ| / 2 ≤ turnover_limit (换手率约束)
         wᵀΣw ≤ σ_target²                 (波动率目标约束，可选)
         Σ industry_weights ≤ ind_limit   (行业权重约束)
         |style_exposure| ≤ style_limit   (风格暴露约束)
```

### 4.3 v3 版本核心改进：开盘价执行模型

v3 版本之前使用收盘价执行（过于乐观）。v3 改为更现实的开盘价执行：

| 项目 | v2 (收盘价) | v3 (开盘价) |
|------|------------|------------|
| 买入价格 | 收盘价 | **开盘价** |
| 卖出价格 | 收盘价 | **开盘价** |
| 新买入当日收益 | 无（T+1 才计入） | **开盘到收盘** |
| 持有当日收益 | 次日开始 | **全天收益** |
| 卖出当日收益 | 全天 | **仅开盘跳空** |
| 涨跌停判断 | 收盘涨跌停 | **开盘跳空涨跌停** |
| 信号延迟 | signal_delay=1 | signal_delay=1（T 日信号 → T+1 开盘执行） |

## 六、核心问题诊断

### 6.1 Optimizer vs Top30 差距分析

Top30 ndrop5 策略（夏普 1.009）显著优于 Optimizer（夏普 0.791），差距来源分解：

| 因素 | 影响 | 说明 |
|------|------|------|
| **Alpha 留存率低 (~43%)** | 最大 | 风险约束 + 换手惩罚 + 权重上限吃掉了过半 alpha |
| **交易成本** | 中等 | 千五滑点 + 千二手续费，Top30 换手 18x 成本约 12%/年，Optimizer 换手 4.5x 成本约 3%/年 |
| **波动率约束降仓** | 双向 | 降低了收益也降低了回撤，夏普略有提升 |
| **行业/风格约束** | 较小 | 行业约束影响不大；风格约束反而有害 |

### 6.2 Alpha 留存率低的原因

1. **风险模型的"风险"与"alpha"高度重叠**：alpha 因子本身带有风格暴露（小市值、高波动、高换手等），风险约束在压制风险的同时也压制了 alpha
2. **换手惩罚 tp=1.5 较强**：为了控制换手率，牺牲了部分 alpha 捕捉
3. **15% 个股权重上限**：限制了高 alpha 股票的贡献
4. **候选池 150 只**：从全市场 5000+ 只中选前 150，alpha 已经经过了一层筛选

### 6.3 潜在改进方向

| 方向 | 预期效果 | 实现难度 |
|------|---------|---------|
| 增加 alpha 因子（质量/数量） | 提升基础 alpha | 中 |
| 因子择时（动态调整因子权重） | 提升 alpha 稳定性 | 高 |
| 行业配置增强（行业轮动） | 提升行业 alpha | 中 |
| 弱化风格约束（已验证有害） | 提升收益 | 低（已做） |
| 降低换手惩罚 + 更优调仓频率 | 平衡 alpha/成本 | 低（已做） |
| 改进风险模型（更精准的风险估计） | 减少 alpha 的误杀 | 中 |
| RL 替代静态优化器 | 端到端学习交易策略 | 高 |
