## 一、未来信息泄露检查

逐项检查特征日期、预测日期、收益窗口、调仓日和复权数据，确认没有未来信息泄露。

### 1.1 特征生成 — 无未来函数

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 价格/成交量因子 | ✅ 安全 | 全部使用 `shift(n)` 正偏移（取历史值），无 `shift(-n)` 反向取未来 |

### 1.3 Label 构造 — 前复权统一基准，未来收益正确对齐

检查 `src/utils/label_generator/daily_label_generator.py`：

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 前复权方式 | ⚠️ 注意 | 使用**全历史最新复权因子**作为统一基准：`adj_close(t) = close(t) * adj_factor(t) / latest_factor`。这是"事后视角"的前复权，训练时使用未来复权因子，但预测时也用同样方式计算 label，训练和推理一致，不构成泄露 |
| 未来收益计算 | ✅ 正确 | `label_hd = adj_close(t+h) / adj_close(t) - 1`，使用 `shift(-horizon)` 取未来价格 |
| Rank label | ✅ 安全 | `groupby("trade_date").rank(pct=True)`，只在同日截面内排序 |
| 边界处理 | ✅ 正确 | 最后 20 天（最大 horizon）的 label 为 NaN，不会被训练使用 |

**关于复权因子的说明**：使用全历史最新复权因子是行业常见做法（类似 Qlib 的 `$close` 前复权字段），因为复权因子只影响收益的"数值缩放"，不改变股票间的相对排序。训练和测试使用相同的复权基准，不存在信息不对称。

## 二、核心回测代码 Review

### 2.1 样本筛选

**代码位置**：`src/backtester/simple_backtester.py` 第 680-700 行附近

| 筛选维度 | 实现方式 | 评价 |
|---------|---------|------|
| ST 股过滤 | `filter_st` 配置项，读取 `st_stock` 字段 | ✅ 正确，使用当日 ST 状态 |
| 停牌过滤 | `filter_suspend` 配置项，通过成交量=0 判断 | ✅ 正确 |
| 新股过滤 | `filter_new_stock_days`，根据上市日期判断 | ✅ 正确 |
| 流动性过滤 | `min_avg_amount_20d`，20 日日均成交额阈值 | ✅ 正确，使用历史成交额 |
| 涨跌停过滤 | `forbid_buy_limit_up/down`，根据涨跌幅判断 | ✅ 正确，使用当日涨跌停状态 |

### 2.2 Label 构造

**代码位置**：`src/utils/label_generator/daily_label_generator.py`

- **收益标签**：`label_hd = adj_close(t+h) / adj_close(t) - 1`，h ∈ {1,2,3,5,10,20}
- **排序标签**：`label_rank_hd` 为同日截面上 `label_hd` 的百分位排名
- **复权方式**：以全历史最新复权因子为基准的前复权（训练/推理一致）
- **评价**：✅ 逻辑正确，与 Qlib 等主流框架一致

### 2.3 特征生成

- **价格量因子**：收益率、波动率、动量、翻转、换手率等，全部基于历史数据
- **基本面因子**：ROE、ROA、毛利率、负债率等，PIT 匹配
- **资金流因子**：大单/中单/小单净流入，北向资金等
- **增强 alpha 因子**：MACD、RSI、52周高点距离、OBV、营收加速度等
- **评价**：✅ 因子计算逻辑正确，无未来函数

### 2.4 排序分组

**PreparatoryBacktester（快速回测）**：
- 按预测分数降序排列，取 top-k 持有
- 每期卖出持仓中分数最低的 n 只，补入新的高分股
- 等权重分配
- **问题**：缺少 signal_delay，同日预测和同日收益对齐

**SimpleBacktester（真实回测）**：
- signal_delay=1，t 日信号 t+1 交易
- 支持行业中性化排序（可选）
- 支持波动率加权（可选）
- 支持个股权重上限（可选）
- **评价**：✅ 逻辑完整，符合 A 股 T+1 交易规则

### 2.5 收益计算

**PreparatoryBacktester**：
- 直接用 label（未来收益）的均值作为组合收益
- 换手率 × 成本率 扣除交易成本
- **问题**：简化了成交逻辑，不考虑涨跌停、滑点的实际影响

**SimpleBacktester**：
- 按实际成交价（open/close）计算收益
- 考虑整手交易（100 股一手）
- 考虑涨跌停无法成交
- 考虑手续费、印花税、过户费
- 考虑滑点
- **评价**：✅ 贴近真实交易

### 2.6 Code Review 结论

- ✅ **核心逻辑正确**：样本筛选、label 构造、特征生成、排序分组、收益计算的主体逻辑均无问题
- ⚠️ **preparatory_backtester 有局限**：缺少 signal_delay 和真实成交模拟，仅用于快速验证，不能作为最终结论依据
- ✅ **simple_backtester 完整可靠**：涵盖 A 股主要交易约束

### 5.2 尾部 vs 中部汇总

| 分组 | 日均股票数 | Rank IC | 胜率 | ICIR |
|------|----------|---------|------|------|
| 大跌尾（后 10%） | 531 | **+0.231** | 99.9% | 37.3 |
| 下跌组（10-30%） | 1063 | +0.110 | 96.0% | 28.0 |
| 中部（30-70%） | 2127 | +0.048 | 72.9% | 9.6 |
| 上涨组（70-90%） | 1063 | -0.063 | 10.2% | -19.7 |
| 暴涨尾（前 10%） | 532 | **-0.128** | 4.5% | -26.8 |

### 5.3 核心发现

1. **IC 从正到负单调递减**：第 6-7 组（收益≈0）IC 穿过零点
2. **大跌尾强正 IC**：模型给低分的股票确实跌得最多（IC=0.231，胜率 99.9%）
3. **暴涨尾强负 IC**：模型给高分的股票反而涨得最少（IC=-0.128，胜率仅 4.5%）
4. **全市场 IC 主要由大跌尾贡献**：中部 40% 股票的 IC 仅 0.048
5. **模型不是"收益排序器"，而是"暴跌风险识别器"**：
   - 高分 = 不会大跌（但也不会大涨）
   - 低分 = 容易暴跌

## 六、行业中性化 IC 验证

|------|-----|-----|------|
| 原始 Rank IC | 0.1203 | 14.65 | 基准 |

| IC 变化 | **-2.0%** | — | 行业中性后 IC 反而微升 2% |

### 6.2 结论

**IC 几乎不来自行业暴露，模型有真实的个股选股能力。**

- 行业中性后 IC 不仅没下降，反而微升 2%，说明行业暴露不仅不贡献 alpha，还略微干扰了排序质量。
- 行业内 IC 0.1196 与原始 IC 几乎一致，进一步证明模型在每个行业内部都有稳定的选股能力。
- 这与"模型是尾部风险识别器"的画像一致——尾部风险是个股层面的，不是行业层面的。

- **高波动环境 IC 更高**（0.148 vs 0.115），但 IR 略低因为波动也大。模型在高波动期区分度更强。
- **模型不是"只在下跌市有效"的风控型因子**——各类环境中都有效，震荡市最强，下跌市也不弱。可以作为主 alpha 使用。

## 八、多头诊断

### 8.1 多空两侧 IC 分解

> 在未来收益排名前 50%（多头侧）和后 50%（空头侧）的股票中分别计算 IC。

| 指标 | 值 | IR | 说明 |
|------|-----|-----|------|
| 多头侧 IC（label > 0.5） | **-0.1311** | -25.42 | 跑赢中位数的股票中，预测分越高 → 实际排名越低 |
| 空头侧 IC（label < 0.5） | **0.2652** | 39.65 | 跑输中位数的股票中，预测分排序非常准 |

**极度不对称的 IC 结构**：空头端 IC 是多头端绝对值的 2 倍，且符号相反。模型的 alpha 主要来自"避开烂股票"，而不是"找到牛股"。

### 8.2 Top-K 收益分析

| Top 50 平均收益 | 0.5253 | +0.0252 |
| Top 100 平均收益 | 0.5279 | +0.0278 |

- Top 组有正超额，但幅度不大（Top 10% 超中位数 0.034 rank 单位）。
- **Bottom 组的负超额是 Top 组正超额的约 3 倍**（-0.098 vs +0.034）。
- Top 50 命中率（跑赢中位数）53.7%，Top 100 命中率 54.4%——只是略高于随机。

### 8.3 上行/下行捕获率

| 指标 | 值 | 随机基准 |
|------|-----|---------|
| 上行捕获率（真实Top10% → 预测Top10%） | 8.64% | 10% |
| 上行捕获率（真实Top10% → 预测Top20%） | 16.69% | 20% |
| 下行捕获率（真实Bot10% → 预测Bot10%） | **28.38%** | 10% |

- **上行捕获率低于随机**：模型找不到真正的大牛股。真实涨幅前 10% 的股票，只有 8.6% 被模型预测进前 10%。
- **下行捕获率接近 3 倍随机**：模型非常擅长抓大跌股。真实跌幅前 10% 的股票，有 28.4% 被模型预测进后 10%。
- 典型的"质量因子"或"防御因子"特征——擅长排雷，不擅长找牛股。

## 九、综合结论

### 7.1 模型本质

**grid0188 是一个"暴跌尾部风险识别器"，而非传统意义上的收益排序模型。**

- 它擅长识别"哪些股票会跌得很惨"（大跌尾 IC=0.231，胜率 99.9%）
- 它完全不擅长识别"哪些股票会涨得最好"（暴涨尾 IC=-0.128，胜率仅 4.5%）
- 它的预测能力高度集中在高波动、高风险的股票上（最高波动组 IC 是最低波动组的 3.1 倍）
- 中部 60% 的股票上 IC 仅 0.048，几乎没有预测能力

### 7.2 对"大市值 IC 高但沪深 300 IC 低"的解释

1. **波动率差异**：沪深 300 成分股波动率低（处于波动率分位 1-2），模型在低波动股票上 IC 本来就只有 0.05-0.06
2. **尾部稀缺**：沪深 300 很少出现极端暴跌行情（机构持仓稳定 + 国家队托底），模型最擅长的尾部识别场景在沪深 300 里很少见
3. **行业结构**：沪深 300 以金融、传统周期为主，模型因子可能在这些行业效果差；而成交额 top 组以电子、TMT、新能源等高波动成长股为主，正好是模型的"舒适区"
4. **定价效率**：沪深 300 机构覆盖充分，定价效率高，alpha 空间小
5. **预测离散度**：沪深 300 内预测值的离散度仅为全市场的 74%，模型在宽基内"选不出差异"

### 7.3 策略启示

| 策略方向 | 适用性 | 说明 |
|---------|--------|------|
| 纯多头（沪深 300 增强） | ❌ 差 | 模型不擅长找上涨股，宽基内 IC 太低 |
| 纯多头（全市场 top 组合） | ⚠️ 中等 | top 组合涨不过暴涨尾，但能避开大跌尾 |
| 空头策略（做空低分股） | ✅ 好 | 低分=大跌，这是模型最强的预测能力 |
| 尾部风险对冲 | ✅ 很好 | 用模型低分股做对冲，成本低、效率高 |
| 增强型选股（剔除尾部风险） | ✅ 好 | 在任何选股逻辑中，用模型剔除尾部风险股 |
| 高波动股票池内选股 | ✅ 好 | 在高波动股票中做排序，IC 是全市场的 1.3 倍 |

### 7.4 后续建议

1. ~~行业中性化验证~~ ✅ 已完成（见第六章）：IC 完全不来自行业暴露
2. **补充上涨侧因子**：如果目标是宽基增强，需要补充针对上涨侧的因子（如动量质量、盈利超预期、分析师预期上调等）
3. **空头回测**：直接测试"做空最低分 50 只"策略的收益曲线和风险指标
4. ~~条件 IC~~ ✅ 已完成（见第七章）：震荡市最强，下跌市也不弱
5. **多模型融合**：训练一个专门预测上涨侧的模型，与当前尾部风险模型融合
6. **Label 调整**：考虑使用非对称 label 或尾部专用损失函数，强化尾部预测能力
