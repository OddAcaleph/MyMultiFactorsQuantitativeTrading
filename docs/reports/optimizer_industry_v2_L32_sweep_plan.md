## 五、分析方法

### 5.1 极差分析（直观分析）

对每个因子，计算各水平下的平均夏普比率：

```
K_i = 因子第i水平的平均夏普
R = max(K_1, K_2, K_3, K_4) - min(K_1, K_2, K_3, K_4)  （极差）
```

- **极差 R 越大** → 该因子对结果影响越大
- 可以直接看出每个因子的**最优水平**（K最大的水平）
- 按 R 排序得到因子重要性排名

### 5.2 方差分析（ANOVA）

计算各因子的平方和、自由度、均方，进行 F 检验：

```
SS_T = Σ(y_i - ȳ)²           （总平方和）
SS_A = n_level × Σ(K_Ai - ȳ)²  （因子A的平方和）
SS_e = SS_T - ΣSS_factor       （误差平方和）

MS_A = SS_A / df_A             （因子均方）
MS_e = SS_e / df_e             （误差均方）
F_A = MS_A / MS_e              （F值）
```

- **F > F_临界值** (α=0.05) → 因子显著
- **贡献度** = SS_factor / SS_total × 100%
- 用空白列（未分配因子的列）估计误差

### 5.3 最优组合确定

1. **显著因子**：取最优水平（K值最大的水平）
2. **不显著因子**：取基准值或最经济水平（如换手率低的）
3. **验证实验**：用最优组合参数跑一次完整回测，确认结果与预测值吻合

### 5.4 预测最优值

```
ŷ_opt = μ + Σ(K_opt_factor_i - μ)
```

其中 μ 为总均值，K_opt_factor_i 为各显著因子最优水平的均值。

## 六、执行计划

### 6.1 资源估算

- 实验数量：32 组
- 单组耗时：约 8~10 分钟（1417 次优化，每次 ~34ms）
- 串行总耗时：约 4.5 小时
- 4 worker 并行：约 1.2 小时

### 6.2 执行步骤

```
阶段1：生成实验表 + 批量执行
  ├── 生成 32 组实验配置（JSON）
  ├── 并行执行（4 worker）
  └── 收集结果到汇总表

阶段2：极差分析
  ├── 计算各因子各水平均值
  ├── 计算极差 R，因子重要性排序
  └── 确定各因子最优水平

阶段3：方差分析
  ├── 计算 SS, df, MS, F 值
  ├── 显著性检验（p < 0.05）
  └── 计算各因子贡献度

阶段4：最优组合验证
  ├── 预测最优组合的夏普
  ├── 跑验证实验
  └── 确认实际值与预测值偏差 < 5%

阶段5：（可选）第二轮精调
  ├── 对 Top-3 显著因子加密水平
  ├── L9 正交精调
  └── 最终最优参数
```

## 八、风险与注意事项

1. **过拟合风险**：32组实验可能存在过拟合，需用 OOS（2026年数据）验证
2. **正交表假设**：正交实验假设因子间无交互作用，若交互显著可能偏差
3. **单模型限制**：当前用单模型，后续集成模型可能参数最优值不同
4. **计算时间**：确保并行 worker 数量合理，避免资源竞争
