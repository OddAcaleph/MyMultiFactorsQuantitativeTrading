### 1.2 新增因子（11个）

相比原始61因子模型，新增了以下11个增强alpha因子：

| 因子名称 | 类别 | 逻辑 |
|----------|------|------|
| amihud_20 | 流动性 | 20日Amihud非流动性比率 |
| turnover_vol_20 | 成交量 | 20日换手率波动率 |
| downside_vol_20 | 波动率 | 20日下行波动率 |
| max_drawdown_60 | 波动率 | 60日最大回撤 |
| main_net_ema_20 + main_net_ema_slope_20 | 资金流 | 主力净流入20日EMA及其斜率 |
| main_net_consecutive | 资金流 | 主力净流入连续天数 |
| main_net_amount_ratio_20 | 资金流 | 主力净流入占成交额比例20日均值 |
| industry_rank_ret_20 | 行业 | 20日收益行业内排名 |
| industry_vol_20 | 行业 | 行业20日波动率 |
| momentum_volume_interaction | 交互 | 动量×成交量 交互因子 |
| roe_growth_interaction | 交互 | ROE×营收增长 交互因子 |

### 1.3 删除/停用的因子

从原始特征中移除了以下低质或冗余因子：
- adj_factor, pre_close, open, high, low, close（价格原始值，无预测价值）
- change（与pct_chg高度相关）

### 1.4 特征处理

- **横截面处理**: 缩尾 (winsorize) + Z-score 标准化，按交易日独立进行
- **行业中性化**: 基本面因子（ROE/ROA/营收增速）减去行业均值
- **标签**: label_rank_5d（5日远期收益排名，0~1之间）

## 3. 回测策略

### 3.1 回测约束（全约束）

| 约束类型 | 具体规则 |
|----------|----------|
| 股票池过滤 | 剔除ST/*ST、停牌、上市不足60日新股 |
| 涨跌停限制 | 涨停不能买，跌停不能卖 |
| 流动性约束 | 20日日均成交额 ≥ 5000万元 |
| 流动性约束 | 单次买入金额 ≤ 20日均成交额的5% |
| 行业约束 | 任一申万一级行业持仓 ≤ 10只 |
| 行业约束 | 任一行业市值占比 ≤ 20% |
| 个股约束 | 单只股票权重 ≤ 3% |
| 换手约束 | 违反约束则顺延选择下一只 |
| 交易成本 | 买入佣金0.05%，卖出佣金0.15%+印花税 |
| 滑点 | 0.10% |
| 成交价格 | 开盘价 |
| 信号延迟 | 1天（T日预测，T+1交易） |
| 最小交易单位 | 100股 |

### 3.2 网格搜索最优参数

对5个参数进行了网格搜索，共405组组合：

| 参数 | 搜索范围 | 最优值（夏普） | 最优值（收益） |
|------|----------|---------------|---------------|
| topk | 20, 30, 50, 80, 100 | **30** | 30 |
| n_drop | 3, 5, 10 | **10** | 10 |
| 调仓频率 | 3d, 5d, 10d | **5d** | 3d |
| 流动性阈值 | 2000万, 5000万, 1亿 | 无影响* | 无影响* |
| 单票权重上限 | 3%, 5%, 8% | **3%** | 3% |

> *流动性阈值对结果几乎无影响，模型选出的股票本身流动性充足

### 3.3 参数敏感性分析

**topk 影响**:
- topk=30 综合最优（平均年化38%，夏普1.15）
- topk=20 太集中，波动大
- topk=50/80/100 太分散，收益被稀释

**n_drop 影响**:
- n_drop=10 全面优于 3/5
- n_drop=10 平均夏普1.23，n_drop=3 只有1.02
- 更大的调仓幅度能更好地捕捉alpha

**调仓频率影响**:
- 5天调仓夏普最优（1.24）
- 3天太频繁（成本高，夏普0.92）
- 10天太慢（alpha衰减）

## 5. 关键发现与结论

### 5.1 因子优化效果显著
- IC从约0.06提升到0.16，提升约150%
- 新增的11个因子（尤其是资金流类和交互因子）贡献显著
- IC IR高达5.8，因子稳定性极强

### 5.2 回测参数对结果影响巨大
- 最初的保守参数（topk=50, n_drop=5, 权重3%）年化仅3.2%
- 优化后（topk=30, n_drop=10, 5d）年化提升到40%+
- 核心原因：n_drop=10让调仓更充分，topk=30让alpha更集中

### 5.3 流动性约束不构成瓶颈
- 2000万/5000万/1亿三个阈值结果完全一样
- 模型选出的股票本身都是高流动性标的

### 5.4 僵尸持仓问题
- 有4只股票（000616.SZ、000005.SZ、600432.SH、002477.SZ）因长期停牌/退市一直无法卖出
- 这些"僵尸持仓"占仓位约4-5%，对收益有一定拖累

### 5.5 改进方向
1. 处理僵尸持仓：对长期停牌股票计提减值或从市值中剔除
2. 尝试非对称损失函数，提升多头选股能力
3. 尝试波动率加权或风险平价，降低回撤
4. 增加行业分层抽样，进一步分散行业风险
5. 优化交易成本模型，考虑冲击成本
